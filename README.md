### 1. فتح الموقع محلياً:

- افتح `index.html` في أي متصفح

### 2. رفع الموقع على Netlify:
- اذهب إلى: https://app.netlify.com/drop
- اسحب ملف `index.html` وأفلته في الموقع
- أو اضغط "Deploy manually" واختر الملف

### 3. ربط الدومين:
- في Netlify: Site settings → Domain management
- أضف: df-alshamal.com
- اتبع خطوات DNS
